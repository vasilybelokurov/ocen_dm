    Known gaps and inconsistencies¶

    Found in the 2026-10-13 audit. Each item is open unless marked otherwise.

    1. Baseline counts use the old (schema-1) products. In progress.
    2. dftwo_counts_20260923, rho20scan_* and mpsscan_* used schema-1 counts (star-weighted bin average, biased; see counts.py). Their frozen inputs still replay exactly; the old products are kept as *_schema1_20260923.*.
    3. The canonical ocen_counts_*.json are schema 2 since commit 1af8c33. The base model was refitted with them on 2026-10-13 (results/df/dftwo_counts_area_20261013); the scans have not been rerun.
    4. Docstring and metadata drift.
    5. Fixed 2026-10-13: the bin/build_count_profiles.py docstring described the old quantile nodes.
    6. selection/field_template.py:107 writes "parallax_over_error_max": 5 into the product's cuts metadata, but no parallax cut is applied (parallax_cut: none). The metadata is misleading.
    7. likelihood.py:251 _edr3_ours admits that its note string describes an obsolete construction.
    8. Stale provenance records.
    9. provenance/manifest.json and checksums.txt list vasiliev2021_gc_members/clusters.zip at data/raw/vasiliev2021_gc_members/clusters.zip. That directory is empty, and the copy actually used is the external <code>/apogee_halo_rotation/.../vasiliev_baumgardt_2021_clusters.zip.
    10. The manifest also keeps an obsolete kuzma2026_members.* row with status manual and exists=false, next to the real kuzma2026_members.txt entry.
    11. data/raw/baumgardt_gc_catalogue/ is empty because the file is referenced from CAT, which is intended.
    12. The T3 product's ocen_raw.manifest says unregistered, because it was built before the manifest entry existed.
    13. Registry incomplete.
    14. provenance/datasets.yaml omegacat_vi_kinematics has files: [], although 22 files are downloaded and md5-verified in the manifest.
    15. datasets.yaml omits the following:
      • STREAMFINDER 2021 and 2024, HST LP (all in configs/data.yaml only).
      • Tango Zenodo 4300977, gc_catalog_full.fits, Gaia XP/Andrae pulls.
      • Hunter, Portail, McMillan and MWPotential2014_mod potentials; DB98; GSE contours.
      • MIST/minimint BC tables; the K8 WSDB field template; T2 (covered by product metadata only).
      • Baumgardt+2018 RVs, planned in docs/DATA_GAPS_PLAN.md but never ingested.
    16. Products without builders.
    17. S2 stream5455_gaia_errors.npz, which every stream fit depends on.
    18. S5 XP pulls.
    19. The S1 MRT→FITS conversion, which has no checksum for the FITS.
    20. External path dependencies outside the repository and CAT.
    21. The VB21 zip under <code>/apogee_halo_rotation.
    22. The oCen_bar potentials and GSE contours under OB, reached through two different path conventions.
    23. McMillan17 from the installed AGAMA package, so results depend on the AGAMA version.
    24. Inconsistent systemic values across modules.
    25. μ_sys: cluster.MU_SYS = (−3.257, −6.730); the K8 template frame uses (−3.2514, −6.7444), derived from K6; streams/frames.py uses (−3.2499, −6.7461).
    26. v_los: 232.7 in cluster.py, 232.6 in field_template.py, 232.78 in frames.py and in the Baumgardt registry.
    27. Each choice may be intentional, but none is documented as a single source.
    28. Selection inconsistencies within the light and tracer chain.
    29. L2 (Jeans tracer and K4 depth term) uses oMEGACat selection_hq_f625w star counts inside 25″.
    30. C1 (DF baseline) deliberately avoids that flag as 12–15 % radially incomplete.
    31. K10 hst_quality uses a flag that contains a CMD cut (project journal, 2026-10-08; flagged and not changed).
    32. Unverified references (per datasets.yaml or the project journal):
    33. Trager 1995 ADS link (verified: false).
    34. Baumgardt+2019 DOI (verified: false).
    35. Baumgardt GC database version.
    36. Kuzma+2021 (registered, no data, verified: false).
    37. Hunter+2024 paper.
    38. Origins of the Portail17 and MWPotential2014_mod .ini files.
    39. GSE contours.
    40. Andrae+2023 reference.
    41. The meaning of the VB21 profile undocumented_col12.
    42. Registered or present but unused.
      • The O1 oMEGACat files: alternative binnings, equipartition, .dat twins, notebook.
      • S3 STREAMFINDER 2021.
      • The unused Hunter24 variants, pot_bar_mod, PriceWhelan19/22, MWPotential2014.
      • The large XP catalogues in CAT.
      • datasets.yaml entries with no data: noyola2006_sbp (no NGC 5139 rows), omegacat_ii_astrometry (no files, "not used until validated"), kuzma2021_edr3_tails, youakim2023_debris.
    43. Quarantined stale products.
      • proc/kinematics/_stale_pre_centre_fix/ holds three products built before the 2026-09-19 centre correction: ocen_outer_fit_quality, ocen_pm_dispersion_ours and ocen_pm_dispersion_mixture. Its README says they feed only historical figures.
      • plotting/constraints.py:437 writes a fresh ocen_outer_fit_quality.ecsv to the non-stale path when save=True. None currently exists there.
      • No code reads the other two stale files.
    44. Rebuild date versus snapshot.
      • ocen_pm_dispersion_edr3_ours.ecsv was rebuilt on 2026-10-11, after the baseline. The values were verified identical today, but the loaders auto-build missing products, so a fresh checkout can silently produce data that differ from the frozen snapshots (README:162–165).
      • Run directories freeze their inputs (data_snapshot.json, count JSON with sha256), which protects the recorded runs.
    45. Heavy and uncommitted items.
      • results/streams/m5_gaia_knee.npz (242 MB) is a one-off diagnostic cache.
      • bin/streams/fit_bar_ocen.py has uncommitted edits, and check_stream_coordinate.py (a consumer of S4) is untracked.
